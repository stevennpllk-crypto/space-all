# NASA imagery

Original image files downloaded from NASA's official Image and Video Library API. See NASA_ASSET_CREDITS.json for NASA IDs, source pages, asset URLs, and creator credits.

NASA media is generally reusable under NASA's media guidelines, but individual items may contain third-party copyrighted material. Check each credit before redistribution. Do not use NASA insignia or imply NASA endorsement.

Unity import compression and platform texture limits should be configured separately for Android performance.
